# ChatGPT確認用SSRページ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** XServer VPSで公開できる`/ai-view`を、通常UI/APIと共通のserver observability surfaceから生成し、JavaScriptなしのHTTP GETで実データとFail Closed状態を確認できるようにする。

**Architecture:** 既存の判定API組み立て処理を`loadDecisionStatusSurface()`へ移し、認証付きJSON APIとSSRページが同じsurfaceを読む。Aster read-only取得は共有loaderへ抽出し、`buildDecisionViewModel()`と新しい公開用`buildAiViewDocument()`を使って、ページ側に判定ロジックを複製しない。公開用document modelは許可フィールドだけを明示的に投影し、React Server ComponentがテキストHTMLを描画する。

**Tech Stack:** Next.js 16 App Router, React Server Components, TypeScript, Node.js `fs/promises`, existing Aster read-only client, `tsx` self-tests, Next webpack build.

**Spec:** `docs/superpowers/specs/2026-08-28-ai-view-design.md`

## Global Constraints

- Vercelは使用しない。canonical deploymentはXServer VPS `professional-dismanager.net`。
- V12・PENGU・V52のロジック、Entry/Exit、Gate、Kill Switch、runner、注文処理を変更しない。
- 注文・取消・決済・テスト注文・synthetic order・建玉変更を実施しない。
- `readOnly=true`と`tradingMutation=0`を維持する。
- 公開HTMLにAPIキー、秘密鍵、認証情報、環境変数、秘密ファイルの絶対パス、注文ID、残高、数量、価格を出さない。
- データ取得不能は`UNKNOWN`、`UNAVAILABLE`、`STALE`、`DATA ERROR`として表示し、推測値を出さない。
- 実装前にテストを追加し、失敗を確認してからproduction codeを追加する。

export type DecisionStatusSurface = DecisionStatusSnapshot & {
  v12Observability: Awaited<ReturnType<typeof loadV12DecisionObservability>>;
  v52Top2Observability: Awaited<ReturnType<typeof loadV52Top2Observability>>;
  penguRuntime: Awaited<ReturnType<typeof loadPenguRuntimeObservability>>;
};

export async function loadDecisionStatusSurface(options: { force?: boolean } = {}): Promise<DecisionStatusSurface> {
  const snapshot = await loadDecisionStatus(options);
  const v12Observability = await loadV12WithSafeFallback();
  const [v52Top2Observability, penguRuntime] = await Promise.all([
    loadV52Top2Observability(),
    loadPenguRuntimeObservability(),
  ]);
  const runtime = applyRuntimeTruth(snapshot.runtime, v12Observability, v52Top2Observability, penguRuntime);
  return { ...snapshot, runtime, v12Observability, v52Top2Observability, penguRuntime };
}

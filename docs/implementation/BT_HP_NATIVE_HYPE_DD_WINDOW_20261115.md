## 監査の目的と範囲

研究BTの最大DDを時価評価口座残高（MTM）のピーク→谷として再計算し、その区間で終了した**モデル決済済み**取引をロジック／通貨／routeで集計。**含み損を含む最大DDを、決済損益へ直接原因帰属したものではない**。監査元台帳はOwner PC上のPrivateフォルダに保持し、GitHubには確認手順と非機密集計だけを保存。

# RESIDUAL AVAX LONG −3.5%／2時間監視＋−5%緊急STOP 仕様・LIVE実装条件（2026-10-23）

**対象：RESIDUAL 戦略の AVAXUSDT LONG のみ。研究上の正式採用候補。現行LIVEの有効化証明ではない。**

## 意図と優先順位

この機能は損失ヘッジであり、**実装によってBT最終資産が減少しても導入方針を変更しない**。ただし、市場データの価格不一致を未解消のままLIVE有効化したり、保護STOP未設置を放置したりしてはならない。

1. **常設−5%緊急STOP**：戦略所有のAVAX LONGの実平均約定価格に対する価格下落率が−5%に到達すれば、2時間監視の状態・利益保護・6時間EXITを問わず即時リスク解消する。実運用では**取引所ネイティブのSTOP MARKET、reduce-only／close-only相当の保護注文**を約定時から確認・維持する。取引所のトリガーは実際の条件に合うマーク／ラスト価格を定義し、複数価格の混同は禁止。スリッページや価格ギャップで約定損失が−5%を超える可能性は残る。
2. **−3.5%到達後の2時間監視**：取引所トリガー基準の価格が、エントリーの実平均約定価格比で−3.5%以下に一度でも達した最初の時刻を `first_touch_at` として記録。途中で反発しても時刻はリセットしない。**初回接触から2時間後**にまだ価格変化率が−3.5%以下であれば戦略所有量のみ成行決済（reduce-only）。2時間後に−3.5%より回復している場合は監視を終了し、**次回の−3.5%再接触で再監視**。同時に−5%が成立する場合は−5%緊急STOPを優先。
3. **既存EXITを維持**：最大6時間決済、含み益+3%到達後ピークから1.5ポイント逆行のトレーリング、他戦略との既存保有／優先順位制約。時刻の早いEXITが有効。ただし−5%取引所STOPが常設され、通常EXIT後は必ずcancel ACKを照合する。
4. **入口フィルター固定**：RESIDUAL DOGEの新規入口除外、RESIDUAL AVAX LONGにのみ2つのOR見送り条件（AVAX直近確定3h ≤−0.5%かつBTC3h＜0%; AVAX確定6h ≥+2.0%かつBTC6h＜0%）。他7ロジックと他戦略のAVAXは不変。

## 研究BT上の因果・約定契約

- 価格の%は*市場価格のエントリー価格比*であり、証拠金倍率を掛けた口座ROEや手数料差し引き後のNET%ではない。
- 研究M5で安値が−3.5%に触れた場合、該当5分足**完成時刻**で監視開始し、ちょうど24本（2時間）後の5分足**確定終値**が−3.5%以下ならその次のM5始値で決済。翌始値がギャップした場合、悪化した価格のまま計算する。LIVEでは取引所の逐次ティック／時刻を優先しM5確定待ちはしない。
- 緊急STOPはM5安値が−5%以下なら*同じ5分足の間に発動*とみなし、STOP価格と該当5分足始値の**悪い方**でシミュレーションする。M5モデルではイベント時刻は5分足完成時刻として記録するが、これはLIVE発注の速度の保証ではない。
- H1ネイティブ研究エントリーと現物M5始値が一致しないケースが存在する。研究ではM5をH1エントリーへリベースする感度検証ができるが、**平均約定価格との一致が証明されるまでLIVE経済認証とはしない**。相違と最大乖離は証拠として必ず残す。

## 実装の安全必須事項

- 実平均約定エントリー価格・取引所のポジション所有者・残存数量・保護注文IDと注文状態を正本として使用。AVAXを保有する他戦略の数量には触れない。ヘッジ／ネットモードの所有権曖昧さがあればFail Closed。
- 部分約定、分割注文、ポジション数量変動、通常決済と緊急STOPの競合、Reduce-only可否、tickSize・stepSize・注文頻度・数量精度、建玉とストップ残高の差を検証。
- `first_touch_at`／`watch_deadline_at`／保護注文の確定状態を永続化。再起動後は現ポジションと注文を照合し、監視期限が既に過ぎている場合もリスク判定から継続。復元できない場合は新規注文Fail Closedかつオペレーターへ異常通知。
- −5% STOPのvenue ACKおよび再起動後の存在・数量・トリガー価格一致の認証を必須化。Stop-market未対応ならサーバー側ポーリングを**即時保護と偽称しない**。
- Shared Risk／Margin Guard／Kill Switch、既存のストラテジーSTOP、口座Lockを緩めない。保護注文のための資金再配分をしてはいけない。
- 特別なBTC/AVAX相場変動でエントリー直後に既に−5%を超えた場合、異常として明示し、保証不能な指値や未承認の強制決済で処理したと装わない。
- 既存の原価、PnL、先行EXIT、クールダウンへの反映、HPシグナルと実決済理由の一致を監査し、実約定通過証拠を保管する。

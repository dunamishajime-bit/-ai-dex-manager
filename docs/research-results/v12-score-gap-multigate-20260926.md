## 1. 画像の「volume不足」だけでは理由が分からない

年間のraw候補-確定足行は 61,097。最初の拒否理由ではなく、以下は**同一行の重複不合格も全件算入**している。

| 多重チェック | raw候補-確定足行 |
|---|---:|
| 出来高不足 | 39,554 |
| Entry Quality/BTC Regime不合格 | 53,769 |
| 出来高もEntry Qualityも同時に不合格 | 34,907 |
| Strong Regime 0.70超〜通常閾値1.4649未満のScore帯 | 134 |
| 同Score帯で、ほかのBase Gateは通過 | 62 |
| NEUTRALかつvolume≥0.80、Score0.70〜1.00 | 647 |

全候補に対しStrong Score不連続のみで弾かれた件数は少ない。出来高を緩和しても隠れていたEntry Qualityが残る件が多い。スコア閾値を緩和すると、従来の有力銘柄がTop3から押し出される displacement が起きる。

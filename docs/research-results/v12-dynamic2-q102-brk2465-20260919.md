## Dynamic V12 rule tested

V12 keeps the existing 1.50x base allocation contract. Residual capacity may temporarily raise V12 toward 2.00x without changing V12 signals. The added portion is lower priority than the base sleeves. When later base demand requires capacity, only the dynamic V12 addition is trimmed. The trim PnL is marked using Binance USD-M 1-minute prices, with V12 side, entry price, funding, and scenario fee/slippage assumptions.

This is not a blanket 2.00x V12 sizing rule and does not authorize changing the underlying V12 signal/risk model.

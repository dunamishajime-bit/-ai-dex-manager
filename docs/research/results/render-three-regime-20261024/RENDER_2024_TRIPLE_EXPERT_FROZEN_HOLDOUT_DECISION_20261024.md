# RENDER三系統・2024年型の改善研究：2024〜2026年＋新しい8〜10月検証

**日付：2026-10-24 / STATUS：RESEARCH_CANDIDATE_ONLY / 採用・LIVE・Production変更なし**

## 研究の進展と対象

ユーザーの方針：2024年相場に対応した第三の系統を用意し、2026年1〜3月の弱い成績と4〜8月の良い成績を月で固定切替せず、**市場状態で並列評価する**。2024年に有効だった入口が2025/2026年にも効くか、取引数を極力落とさず、1件-10%級の損失回避と最大DD削減を優先する。

従来の2024年4価格型×3出口＝12式は2024年のPFがほぼ全て1未満。2024年1〜7月16日までの旧RNDRUSDT先物・7月26日以降の新RENDERUSDT先物を独立した契約として、2024年の情報を完全に参照できるようにした。

2024年原資料227ファイルをBinance Vision公式`.CHECKSUM` SHA256、ZIP CRC両方で検証（全件PASS）。2024年7月16日の旧RNDR最終決済後に残っているOHLCゼロ出来高の行を全て除外。未上場区間には発火なし。2024年8月〜2026年8月の従来799本の公式ZIPも以前の別研究で全件の公開SHA照合を確認。OIはタイムスタンプ＋10分の公開遅延、Fundingは公表後＋5分、足と価格は確定M5、H1確定時の判定に限定。

## 2024年型として新たに作った入口と出口

新しく**LONG6系統＋SHORT6系統、出口7系統、全84ケース**を同一M5のstop-first、次5分足始値想定、12h同一銘柄クールダウンで計算。旧RNDRと新RENDERは一切ポジション・変動率系列を跨がせない。

2024年前半〜2026年の複数年に渡って比較すると、LONGは2024年で安定せず、SHORTのうち次が有望となった。

1. **A（2024年相場型）：BTC上昇失敗SHORT**
    - 確定1h足BTC騰落率>=+0.28%、RENDER/RNDR直近3h>=+0.7%、
      上ヒゲ>=0.4%、直近15分<=-0.12%、直近1hレンジ内位置<=0.65、
      直近1h成行売り優勢>=3%。
    - TP4% / HARD STOP3% / 保有上限24h / 決済後12hクールダウン。
2. **B（下落反発型）：OI減少を確認した反発失敗SHORT**
    - 直近24h騰落率<=-2%、直近3h反発>=0.7%、事前反発幅>=1.0%、
      直近15分<=-0.17%、直近1hレンジ内位置<=0.50、
      成行売り優勢>=3%。確定OI3時間の減少>=0.6%を追加。
    - 同じTP4% / HARD STOP3% / 24h / 12h cooldown。
3. **C（既存の好調なnative RENDER）**
    - 旧8ロジック共通財布で2026年4〜8月9勝/12件だった既存入口、元の利益保護とクールダウン、保護注文、所有権、Shared Riskを**一切変更しない**。
    - A・Bは独立市場研究候補として同時採点し、仮の相場適合スコアで互いの優先順位を付けたが、Cと統合した正式な3系統スコア・Gross再配分は未実装である。Cを仮の決済価格で合成することはしない。

**採用候補の暫定スコアは相場適合度であり、校正済みの共通口座期待損益ではない**。スコアのラベル変更7件があり、A/Bの出口契約は同一なのでその段階で独立スリーブ損益への影響はなし。

### ロット別の独立スリーブ危険度（マーケット全体のDDではない）

0.5x毎回・30bpsの決済ベース最大DDは2024年-9.347%、2025年-6.438%、2026年1〜8月-13.004%。複利累積増加はそれぞれ+9.914%、+13.354%、+13.721%。0.25xなら最大DDは-4.761%／-3.259%／-6.691%。ロットの小型化だけで各年間同一件数を保持した比較。ただし**保有中のMTM、8戦略統合の損失日、Gross・Margin・他の資金枠競合は未再現**であり、運用DDが15%以下と保証するものではない。

M5モデル価格ベースの1件最大損失-3.3%（3%STOP＋30bps）を観測。モデル外のvenueスリッページやGap、保護Stop不成立は対象外。

## 統合LIVEへ進めない理由／次の採用条件

1. A/Bの新規H1候補が既存native8のRENDER発注と24h以内に9件近接。共通所有権と保有枠が相互に影響する。A/B研究利益を既存nativeの利益に足し合わせない。
2. 正本8ロジックNative・動的Gross・pending exposure・他戦略同時候補・共有Margin・保護注文・手数料・venue部分約定・再起動復旧の因果一致を再計算する必要あり。A/B独立のロットを元のnative filterだけへ無理に押し込まない。
3. 2024年からの3系統は運用を二重/三重に分散する**研究候補**として検証済みだが、A/B/Cの期待値に揃えた優先スコア校正と全8統合DD・JPY損益再計算は未達。
4. 2026年8〜10月は「2026-10-24時点初見」の履歴であって真の未使用前向き期間は以後にしか形成できない。勝率70%目標や3年の安定収益は保証しない。

**結論：2024年型を追加する入口研究は改善したが、正式採用・LIVE実装の判断は引き続き保留。現在のCとShared Risk、安全装置、Production、VPS、HP、建玉、注文は変更なし。**

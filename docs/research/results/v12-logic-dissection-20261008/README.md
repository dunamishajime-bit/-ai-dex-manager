## 検証と限界

H1 Open Quote proxy、固定された非V12候補、観測時点のvenue filtersを利用し、過去tick/L2/pending/margin完全再現ではありません。MTM DDの独立再構成はしていません。これまで検証した期間であり、組み合わせ後の優位性も将来の黒字も証明していません。採用判定はV12全体・前後半で純益/平均損益が正、PF1.10以上、各半期50件以上、最大勝ち1件を除いて黒字、10/20/30bps全てを満たす条件。採用案なし。

全体利益が改善してもV12単体の黒字とは扱いません。今回の結果から黒字化したと主張して本番へ移す変更はありません。引き続き新仮説を検証する場合は、過去の閾値探索を増やすより別期間またはForwardで仮説を固定した検証が必要です。

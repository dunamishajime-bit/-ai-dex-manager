# FET BRK48 LONG 出口改善 — 累積正式採用後8ロジック統合BT

## 前提

- 比較対象: FET SHORTではなくFET LONGのみ。その他7ロジックの入口・出口を固定し、HYPE LONGの新条件とRENDER＋TAOのSHORT3条件をすべて先に累積適用。
- 期間2025-08-10〜2026-08-10、初期1万円・積立なし・複利、10bps通常コスト／30bpsストレス。全8ロジックを出口変化後に時系列動的再選択。
- 確定5分足を用い、当該足の終値でARM、次以降の足のLOWで追従STOP発火、ギャップは不利なOPEN価格にて執行。
- 現行FETはすでに+5%到達後の+3%保護・24h終了・リスクSTOP等を持ち、元のFET決済より前にのみ追加案が変更を許される。
- 価格モデル・歴史的な最適化研究。取引所STOP発注、独立OOS、Task9独立TypeScript経済Parityの認証ではない。

## 採用判断（まだ自動採用しない）

- 利益改善かつDD非悪化の候補を10bpsと30bpsの両方で満たすもの: FET_TRAIL_5P_GIVEBACK_3P, FET_TRAIL_8P_GIVEBACK_4P, FET_TRAIL_5P_GIVEBACK_5P, FET_INITIAL_3H_MINUS1P5_LOW_MFE, FET_INITIAL_4H_MINUS2P_LOW_MFE, FET_COMBO_TRAIL8GB4_PLUS_INITIAL3H, FET_COMBO_TRAIL8GB4_PLUS_INITIAL4H。
- サンプルは年間FETわずか8件。勝率変化は過信しない。採用には経済効果・過学習リスク・本番Venue STOP維持の確認が必要。
- 初期逆行STOPは、FETの回復する損失取引に作用すると負けを大きくする可能性があるため、単体の負け件数だけでは推奨しない。
- 今回は正式採用ではない。VPS/LIVE/Production/注文/HPへの変更なし。既採用HYPE、IdleおよびDOTを維持。

## 研究者の推奨（正式採用前）

- **第一候補：FET LONG +8%到達を確定5分足で確認してから、最高確定含み益から4ポイント逆行したら追従STOP。** 元の+5%→+3%利益保護、24時間出口、既存ハードSTOPを残す。
- 10bpsと30bpsの両方でFET単体損益と統合最終資産が改善し、最大MTM DDも変わらなかった。単体候補の中では総合的に最も一貫した結果。
- 追加の3時間−1.5%低MFE STOPを同時採用した場合：10bps 248,137,522円、30bps 141,914,251円。10bpsでは追従単独より高いが、30bpsは追従単独 143,906,605円より低い。
- 追加の4時間−2%低MFE STOPを同時採用した場合：10bps 247,954,232円、30bps 141,693,514円。時間条件差に最適化依存する懸念がある。
- 初期逆行STOPで従来の負けC002250は実際には悪化し、早期解放による追加候補C002256の1件の勝ちで総利益が伸びた。過学習・流動性・容量再配分に弱いため**初期逆行STOPの正式追加は保留**。
- +8/4案も実際に主としてFET 3取引への作用で利益が増えた小標本。OOS、取引所resident STOPライフサイクル、独立統合Task9 TypeScript Parityが成立する前のLIVE実装はしない。

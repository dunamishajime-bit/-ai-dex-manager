# Y06-R21 SINGLE SLOT — 最終研究候補仕様（2026-11-27）

## 入口A — OLD24

R17で復元した独立DOWNTREND_BREAKのNATIVE_STYLE入口を基準とする。D/12H/6Hの下降方向・BTC相対6H弱さ・新規12H安値突破に関する元の候補生成を保持する。厳密な境界・ATR計算・データ品質条件はR17～R22の保存ソースを正とし、文章のみから再実装しない。

R18のNO_BULL_STRETCHを適用：
- BTCの確定済み24H・72Hリターンがともに正なら見送り。
- 対象銘柄の直近3H下落幅が2ATR超なら見送り。

R21のROOM_SELL_OR_WEEKUPを追加：
- BTCの24H・72Hリターンがともに負のときだけ、次の追加条件を課す。
- 現在の確定足終値と過去168Hの参照安値との差が0.5ATR以上。
- かつ、Binanceの直近確定3H成行売買不均衡が負（売り優勢）、またはBTCの168Hリターンが正。
- BTC混合相場ではR18の条件を維持。
- 必要なデータが欠損する条件を恣意的に補完しない。保存ソースの判定・QAを維持。

出口：H24時間決済またはSTOP8。固定TPなし。

## 入口B — NEW48

R15のASTER_H1を維持する。
- 3H境界で確定済み足を参照。直近3Hの成行買い不均衡（2×taker buy volume / total volume − 1）が+0.15以上。
- 直近3H平均出来高が直前21H平均の1.5倍以上。
- 買い優勢にもかかわらず直近3H価格リターンが負（売り側の吸収）。
- 各境界の適格銘柄から既存スコアで選出。最大3H以内に起点のM5始値を下回る陰線のH1確認を行い、次のM5始値を約定代理価格とする。確認後のQAを再実施。元ソースの候補選択・時刻・重複排除を保持する。
- 入口A/Bで保有枠を共有。1枠保有中は新規R21候補を見送り。

出口：H48時間決済、価格有利方向8%のTP8、またはSTOP8。STOP/TP同一足ではSTOP優先。不利なギャップは約定代理価格に反映。全取引への一律トレーリング、全H24化、全H48化は採用候補としない。

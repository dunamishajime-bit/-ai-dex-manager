# Hajime Remote design

Approved by the user on 2026-10-06: create a personal Windows resident app,
existing XServer VPS relay/MCP server, and Chat plugin. No paid API, new VPS,
Desktop Commander subscription, or artificial monthly action quota.

## Components and boundaries

- Python 3.12+ standard-library VPS service, dedicated unprivileged account,
  loopback port 8798, HTTPS prefix /hajime-remote on the existing domain.
- Windows Python 3.13 app under LOCALAPPDATA/HajimeRemote. Native Win32 screen,
  mouse and keyboard, ordinary-user subprocesses, home-directory file access,
  Tk dashboard and login startup. Outbound HTTPS only; no inbound PC port.
- Stateless Streamable HTTP MCP endpoint /hajime-remote/mcp. OAuth with PKCE,
  exact resource binding, expiring single-use codes, rotating refresh tokens.
  Login uses a short-lived pairing code generated by the PC app, so there is
  no new reusable password to send through Chat.

## Functional contract

Status, PNG screenshot with virtual-screen coordinates, click/text/keys/scroll
batch, window list, list/read/write files, start/poll/stop a PowerShell or Python
command, poll a relay operation. Writes require unique request_id; duplicates
must not repeat the action. A task whose execution is uncertain after a crash
is reported UNKNOWN and never automatically replayed. Offline PC fails closed.
Pause prevents new actions; stop terminates managed command process trees.
GUI consent is retained for Windows elevation; no UAC bypass.

## Data and authorization

Agent credential protected by Windows DPAPI; only its hash stored by the VPS.
OAuth tokens stored as hashes, minimum permissions, no credentials in source.
No public unauthenticated action endpoint. OAuth pairing expires within five
minutes with bounded guessing. Metadata/discovery contain no private data.
File APIs are bounded to the configured Windows user root and reject escape
through symlinks/junctions; private key/config files are not returned.
Audit logs contain operation type/id/time/status, not typed text, commands,
file contents, tokens or images. Results expire; command output is bounded.

## Deployment and acceptance

Independent repo directory/branch under tools/hajime-remote in the existing
GitHub repository; never modify trading source, state, approvals or services.
Back up nginx before adding only new routes; nginx -t before reload. Service
resource limits and rollback disable only this new service/routes. Bootstrap
uses Desktop Commander solely to install and test the replacement.
Test auth, replay, input validation, transport, real subprocess/file effects,
pause/offline and result delivery. Real Windows smoke test reads screenshot,
creates a dedicated test file and runs a harmless command; it must not alter
the user's other files or trade state. Final Chat registration/authentication
requires the owner; do not claim connected until an actual Chat tool call.
